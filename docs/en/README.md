# JYSV HERA user guide

HERA is a terminal for people who work with AI coding agents. These pages explain each feature. For installation and a quick start, see the main [README](../../README.md).

| Page | What it covers |
|---|---|
| [Getting started](getting-started.md) | For beginners: install an AI tool, register a folder, open a terminal, the first conversation |
| [Projects](projects.md) | Registering folders (drag and drop), the start screen, project settings, the folder tree, the backlog panel |
| [Terminal](terminal.md) | Tabs, split view, copy and paste, zoom, fonts, cursor, shells, ConPTY, Windows Terminal import |
| [Agents](agents.md) | The 32 built-in AI CLIs, adding your own, status detection, notifications, accounts |
| [Worktrees](worktrees.md) | Isolated copies of a project for an AI to work in: review, merge or throw away; give several AIs the same task and keep the best |
| [The `hera` CLI](hera-cli.md) | Every `hera` command, with examples, and how agents hand work to each other |
| [Lanes](lanes.md) | Running the lanes plugin's mid and low sessions inside HERA |
| [Session memory](session-memory.md) | Autosave, restoring after a reboot, resuming the exact conversation |
| [Usage](usage.md) | Limits, tokens and cost per agent and per project |
| [Themes](themes.md) | Dark, light, presets, accent colors, your own colors |
| [Updates and privacy](updates-and-privacy.md) | Version check, updating from the app, patch notes, where data is stored |
| [Security](security.md) | Checking a download (signed build provenance, checksums), code signing, how the app is hardened |
| [Troubleshooting](troubleshooting.md) | Fixes for the problems people run into most |

HERA shows its screens in English or Korean, following your computer's language; change it in *Settings → Display language*. These pages give the Korean label in parentheses where it helps you find a button.
