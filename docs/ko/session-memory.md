# 세션 기억

<img src="../images/features/session-memory.jpg" alt="">

HERA 는 열어 둔 탭을 기억해서, 다운 · 업데이트 · 재부팅이 있어도 작업 환경을 잃지 않게 합니다.

## 무엇을 저장하나

프로젝트마다 열린 터미널의 이름, 셸, 실행 중이던 에이전트, 마지막 폴더, 하던 대화, 마지막 화면 내용을 저장합니다. 저장 시점은

- 45초마다, 그리고
- 탭을 열고 닫거나 이름을 바꾼 직후입니다.

그래서 컴퓨터가 갑자기 꺼져도 직전 상태가 남습니다. 실행 중이던 프로그램 자체가 살아 있는 것은 아니고, HERA 가 다시 실행합니다.

## 복원 방식

설정 → “세션 기억 · 재부팅 복구” 의 “다시 켜질 때”:

- **자동으로 이어서 실행** (기본): 터미널이 몇 개씩 차례로 다시 열립니다. 셸은 마지막 폴더에서, 에이전트는 하던 대화 그대로 이어집니다. 개발 서버 같은 프로젝트 명령은 자동으로 다시 실행하지 **않습니다**.
- **화면만 복원**: 탭이 저장된 화면과 함께 돌아오고 “이전 실행에서 복원된 세션입니다.” 줄이 뜹니다. 그 줄의 버튼을 누르기 전에는 아무것도 실행되지 않습니다.
  - **이어하기**: 에이전트를 쓰던 탭에서 대화를 이어서 엽니다.
  - **다시 시작**: 같은 명령을 처음부터 다시 실행합니다.

프로그램이 끝났을 때도 종료 코드와 함께 같은 줄이 나옵니다.

## 대화 그대로 이어가기

두 에이전트는 도구만이 아니라 대화까지 기억합니다.

- **Claude Code**: `--session-id <id>` 로 시작하고 `--resume <id>` 로 복원.
- **Codex**: `resume <id>` 로 복원.

그래서 탭은 “그 폴더의 가장 최근 대화” 가 아니라 자기 대화로 돌아옵니다. 탭에서 `/clear` 를 했다면 그 뒤로는 새 대화를 따라갑니다. [lanes](lanes.md) 보조 세션의 대화는 메인 탭에 절대 쓰이지 않습니다.

다른 에이전트는 자체의 “마지막 대화 이어하기” 옵션 ([에이전트](agents.md) 의 **이어하기 인자**)을 쓰거나, 폴더에서 새로 시작합니다.

## 셸의 폴더

HERA 는 셸이 지금 있는 폴더를 따라갑니다. 셸이 보내는 표준 폴더 알림(OSC 7, 9;9)을 읽고, Windows 에서는 PowerShell · cmd 프롬프트에 찍힌 폴더도 알아봅니다. 복원된 셸은 그 폴더에서 열리고, 폴더가 없어졌으면 프로젝트 폴더로 열립니다.

## 컴퓨터를 켜면 자동 실행

설정의 **컴퓨터를 켜면 HERA 자동 실행** 을 켜면 로그인할 때 HERA 가 켜지고 위 방식으로 세션을 되살립니다. 설치한 HERA 에만 적용되고 포터블이나 개발용 사본에는 적용되지 않습니다. 창 · 알림의 “숨긴 채로 시작”, “트레이로” 와 함께 쓰면 트레이에서 조용히 기다립니다.

## 저장 위치

HERA 데이터 폴더의 `sessions.json` 입니다. [업데이트와 개인정보](updates-and-privacy.md#데이터-저장-위치) 를 보세요.
