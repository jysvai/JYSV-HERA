# 문제 해결

## 설치 프로그램이 막힐 때

- **Windows SmartScreen** (“Windows의 PC 보호”): HERA 는 아직 코드 서명이 없습니다. *추가 정보* → *실행* 을 누르세요. 설치는 사용자 단위이고 관리자 권한이 필요 없습니다.
- **macOS Gatekeeper**: 앱이 공증(notarize)되지 않았습니다. 처음 한 번은 응용 프로그램 폴더에서 우클릭 → *열기*, 또는 다음을 실행하세요.

  ```
  xattr -dr com.apple.quarantine "/Applications/JYSV HERA.app"
  ```
- **Linux AppImage** 가 실행되지 않으면: `chmod +x JYSV-HERA-*.AppImage` 후 실행.

## Claude Code · vim · htop 에서 마우스 휠이 안 되거나 방향키처럼 동작할 때

Windows 에서 [터미널](terminal.md#conpty-hera-에-넣은-것과-windows-기본-windows) 문서의 ConPTY 차이 때문입니다. 0.2.1 부터 HERA 는 기본으로 Windows Terminal 의 엔진을 씁니다. 설정 → 터미널의 **최신 ConPTY 사용** 이 켜져 있는지 확인하고, **새** 터미널을 여세요. 이 설정은 바꾼 뒤에 여는 터미널에만 적용됩니다. 다른 문제 때문에 꺼 둔 것이 원인일 수 있습니다.

## 크기를 바꾸거나 탭을 전환한 뒤 화면이 깨질 때

0.2.1 에서 고쳤습니다 (탭을 다시 보일 때 커서와 스크롤 상태가 사라지고, 이모지 폭 계산이 달랐던 문제). 이전 버전이면 업데이트하세요. 0.2.1 에서도 생기면 어떤 프로그램에서 그랬는지와 Windows 버전을 알려 주세요.

## 붙여넣기가 두 번 입력될 때

0.2.1 이전 버그입니다. `Ctrl+V` 가 HERA 에서 한 번, 브라우저 자체 붙여넣기로 한 번 더 들어갔습니다. 0.2.1 이상으로 업데이트하세요.

## lane 이 HERA 탭이 아니라 별도 창으로 열릴 때

다음이 모두 맞을 때만 HERA 가 lane 을 탭으로 엽니다.

1. “HERA 에서 lanes 사용” 이 켜져 있고 실행 방식이 **HERA 탭** 입니다 ([Lanes](lanes.md) 참고).
2. 폴더가 HERA 에 등록된 프로젝트에 속합니다. 등록된 프로젝트에서 Claude 를 열거나 폴더를 등록하세요.
3. lanes 플러그인이 0.3.13 이상입니다. 이전 버전은 Windows 에서 HERA 로 연 lane 만 탭이 되고, 메인 Claude 가 스스로 연 lane 은 창이 따로 열립니다.

그렇지 않으면 lanes 가 의도대로 자기 창을 엽니다.

## AI CLI 가 실행 메뉴에 나오지 않을 때

HERA 가 보는 PATH 에서 도구를 찾을 수 있어야 합니다. HERA 터미널에서 `where claude` (Windows) 또는 `which claude` 로 확인하세요. 셸 프로필이 PATH 에 폴더를 추가하는 경우라면 설정 → 터미널의 **셸 프로필 불러오기** 가 켜져 있는지 확인하거나, 시스템 PATH 에 폴더를 추가한 뒤 HERA 를 다시 시작하세요. 다른 이름으로 설치된 도구는 정확한 명령으로 직접 만든 에이전트로 추가하세요 ([에이전트](agents.md#에이전트-직접-추가)). 설치되지 않은 도구는 “지원하는 다른 AI CLI N개” 아래에 설치 안내와 함께 있습니다.

## 상태 점이 틀릴 때 (계속 작업 중으로 남거나 승인 대기가 안 보임)

상태는 화면 아래쪽에 맞춰 보는 패턴으로 판정합니다. 에이전트 페이지에서 그 도구의 줄을 열어 작업중 · 승인 대기 감지 정규식을 고치세요.

## 파이썬 출력의 한글이 깨질 때

Windows 에서 HERA 는 터미널을 띄울 때 `PYTHONUTF8=1` 을 설정하고 PowerShell · cmd 도 UTF-8 로 시작합니다. 그래도 깨지면 프로그램이 자체적으로 옛 코드 페이지를 쓰는 것은 아닌지, 읽는 파일이 UTF-8 인지 확인하세요. 이미 `PYTHONUTF8` 이 다른 값으로 설정된 환경에서 연 터미널은 그 값을 유지합니다.

## 직접 적은 셸 (WSL, 사용자 명령) 이 시작되지 않을 때

같은 명령줄을 HERA 터미널에서 직접 실행해 보세요. 명령줄은 공백 기준으로 나뉘므로 공백이 든 경로는 큰따옴표로 감싸야 합니다. HERA 가 프로그램을 못 찾으면 기본 셸이 대신 열립니다. WSL 은 `wsl.exe -d <이름>` 의 이름이 `wsl -l` 에 나오는 배포판 이름과 정확히 같아야 합니다.

## 설정 초기화

먼저 HERA 를 종료한 뒤 [데이터 폴더](updates-and-privacy.md#데이터-저장-위치) 에서:

- `config.json` 의 이름을 바꾸면 설정 · 프로젝트 · 테마 · 에이전트가 기본값으로 돌아갑니다. 다음 실행 때 새로 만들어집니다.
- `sessions.json` 의 이름을 바꾸면 열려 있던 탭을 잊습니다.
- 폴더 전체의 이름을 바꾸면 완전히 새로 시작합니다.

삭제하지 않고 이름을 바꿔 두면 나중에 되돌릴 수 있습니다.
