# 프로젝트

<img src="../images/features/projects.jpg" alt="" width="120" align="right">

프로젝트는 HERA 에 등록한 폴더입니다. 터미널, 에이전트, 사용량, 백로그가 모두 프로젝트에 붙습니다.

## 프로젝트 추가

사이드바에서:

- **폴더 추가**: 폴더 하나를 등록합니다.
- **상위 폴더에서 프로젝트 찾기**: 고른 폴더의 하위 폴더를 훑어서 찾은 목록을 보여 줍니다. 인식한 표시(예: `.git`)와 마지막 변경 시각이 함께 나옵니다. 이미 등록한 폴더는 흐리게 “(등록됨)” 으로 표시됩니다. 원하는 것을 체크하고 **N개 등록** 을 누릅니다.

프로젝트가 하나도 없으면 작업 화면에 “프로젝트를 등록하세요” 와 두 버튼이 나옵니다.

## 사이드바 목록

- 프로젝트를 클릭하면 작업 화면이 열리고, 더블클릭하면 바로 새 터미널이 열립니다.
- 고정한 프로젝트가 맨 위, 그다음은 최근에 쓴 순서입니다.
- 각 줄에는 마지막으로 작업한 시각, 오늘 토큰 수, 작업 중 · 승인 대기 · 대기 세션 수를 나타내는 점이 보입니다.
- 프로젝트가 5개를 넘으면 검색창이 나타납니다.
- 줄의 **⋯** 메뉴: 새 터미널, 폴더 열기, 맨 위에 고정 / 고정 해제, 프로젝트 설정.

## 시작 화면

탭이 없는 프로젝트를 열면 시작 화면이 나옵니다.

- **터미널**: 프로젝트에 지정한 셸, 없으면 기본 셸로 엽니다.
- PATH 에서 찾은 AI CLI 마다 카드가 하나씩 있습니다. 카드의 **▶** 는 그 에이전트의 마지막 대화를 이어서 엽니다 (이어하기를 지원하는 에이전트에만 보입니다).
- **팀으로 시작**: 여러 에이전트를 나란히 여는 프리셋 ([에이전트](agents.md) 참고).
- **프로젝트 명령**: 프로젝트 설정에서 만든 버튼.

탭 줄의 **+** 버튼에도 같은 항목과 **외부 터미널에서 열기** 가 있습니다.

## 프로젝트 설정

**⋯** 메뉴 또는 백로그 패널의 톱니바퀴로 엽니다.

| 항목 | 설명 |
|---|---|
| 이름, 경로 | 사이드바에 표시됩니다. 경로를 바꿔도 폴더가 옮겨지지는 않습니다. |
| 색상 | 프로젝트 점의 색 (9가지). |
| 셸 | 이 프로젝트만 다른 셸을 씁니다. “기본값 따르기” 는 설정의 기본 셸을 씁니다. 감지된 셸을 고르거나 `wsl.exe -d Ubuntu` 처럼 명령줄을 직접 적을 수 있습니다. [터미널](terminal.md#셸) 참고. |
| 프로젝트 명령 | 한 줄에 `이름 = 명령` 하나. `#` 로 시작하는 줄은 주석입니다. 각각 시작 화면, **+** 메뉴, 명령 팔레트에 버튼으로 나옵니다. |
| 맨 위에 고정 | 사이드바 맨 위에 둡니다. |

예시:

```
dev = npm run dev
test = npm test
claude-yolo = claude --dangerously-skip-permissions
```

**목록에서 제거** 는 두 번 확인합니다. HERA 가 프로젝트를 잊을 뿐, 폴더는 그대로 남습니다.

## 백로그 패널

`Ctrl+Shift+B` (macOS 는 `⌘B`) 또는 오른쪽 위 패널 버튼으로 엽니다. 너비 340 px 이고, 사용량 탭과 (lanes 를 켰다면) Lanes 탭도 이 패널에 있습니다.

- **마지막 실행**: 언제, 무엇으로, 열려 있거나 작업 중인 세션 수, 승인을 기다리는 세션이 있는지.
- **마지막 변경**: git 브랜치, 앞섬 · 뒤처짐 커밋 수, 변경 파일 수, 마지막 커밋, 변경 파일 일부. git 이 없으면 최근 수정한 파일을 보여 줍니다.
- 이 프로젝트의 **토큰 사용량**.
- **AI 작업 기록**: 에이전트별로 마지막 실행 시각, 세션 수, 마지막으로 시킨 지시, **이어하기** 버튼.
- **할 일**: 프로젝트 체크리스트.
- **메모**: 자유롭게 적으면 입력을 멈춘 뒤 약 0.6초 후 자동 저장됩니다.
- **실행 기록**: 최근 12번의 실행.

폴더가 사라졌으면 패널에 그렇게 표시됩니다.
