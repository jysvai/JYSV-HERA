# 사용량

<img src="../images/features/usage.jpg" alt="" width="120" align="right">

HERA 는 AI 구독을 얼마나 쓰고 있는지 — 한도, 토큰, 추정 비용 — 를 에이전트별 · 프로젝트별로 보여 줍니다. 모든 계산은 각 도구가 이미 남겨 둔 로그 파일을 이 PC 에서 읽어서 합니다. 이를 위해 HERA 가 어디에도 데이터를 보내지 않으며, 터미널이 느려지지 않도록 별도 프로세스에서 처리합니다.

## 사용량 페이지

사이드바의 **사용량** 을 엽니다. **새로고침** 은 지금 다시 계산하고, 그렇지 않아도 창이 보이는 동안 90초마다 갱신됩니다.

처음에는 기존 로그를 전부 읽어야 해서 수십 초에서 몇 분이 걸릴 수 있다고 안내가 나옵니다. 이후에는 새로 생긴 부분만 읽습니다.

### 전체와 프로젝트별

오늘 · 최근 7일 · 최근 30일의 토큰과 비용 합계, 그리고 등록한 프로젝트의 순위가 나옵니다.

### 에이전트별 카드

- **한도 막대** (아래 설명처럼 Claude Code 만). 각 막대에 초기화 시각이 붙습니다: “40분 후 초기화”, “2시간 10분 후 초기화”, 또는 날짜. 막대는 평소 강조색이고, 경고 기준 이상이면 작업중 색, 95% 이상이면 대기 색으로 바뀝니다.
- **출처**: 숫자를 어디서 읽었는지.
- 오늘 / 최근 7일 / 최근 30일의 토큰과 응답 수. 추정 비용(`≈$`)은 Claude 에만 표시됩니다.
- 최근 30일 일별 토큰 차트와 최근 5시간 토큰.
- 30일 기준 **모델별** 상위 6개, **폴더별** 상위 6개.
- 도구가 로그를 남기지 않았으면 “로컬 기록 없음”.
- Antigravity 는 짧은 안내만 있고 토큰 통계는 없습니다.

비용은 공개 API 정가로 환산한 추정치입니다. 실제 청구액이 아니며, 구독제는 정해진 요금을 냅니다. 프로젝트나 모델끼리 비교하는 용도로 보세요.

### 경고 기준

설정 → 창 · 알림의 “사용량 경고 기준”, 기본 80%. 한도 막대가 이 값을 넘으면 색이 바뀝니다.

## 한도 (5시간 · 주간 막대)

Claude Code 는 한도 퍼센트를 상태줄 명령에만 넘겨 줍니다. HERA 에서 보려면 **계정 · 자동 로그인** 페이지에서 “Claude Code 상태줄에서 5시간/주간 한도 % 수집” (Claude 한도 연동) 을 켜세요. Claude 설정 파일을 백업한 뒤 기존 상태줄 명령을 감싸서 값을 HERA 데이터 폴더에 기록하고, 원래 상태줄은 그대로 보여 줍니다. 끄면 원래대로 되돌립니다. claude-token-saver 플러그인이 설치돼 있으면 HERA 가 그 캐시를 자동으로 읽으므로 켤 필요가 없습니다.

## 옆 패널의 사용량

프로젝트의 오른쪽 패널에 **사용량** 탭이 있습니다. “한도 · 토큰 · 프로젝트별 (5분마다 갱신, ↻ 즉시)” 요약과, 전체 페이지를 여는 **자세히** 버튼이 있습니다. 60초마다 갱신됩니다.

## 프로젝트별 숫자

사이드바의 프로젝트 줄에는 오늘 토큰이, 백로그 패널에는 그 프로젝트의 사용량이 나옵니다. 에이전트를 실행한 폴더를 기준으로 합니다.
