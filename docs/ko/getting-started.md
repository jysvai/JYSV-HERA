# 처음 시작하기

터미널이나 AI 코딩 도구가 처음이신가요? 이 페이지는 설치 파일을 받는 것부터 AI 와 첫 대화를 하기까지 한 단계씩 안내합니다. 10분 정도 걸립니다.

## HERA 가 동작하는 방식

HERA 에는 자체 AI 가 없습니다. HERA 는 터미널을 여는 창이고, 직접 설치한 AI 도구(Claude Code, Codex 등)가 그 터미널 안에서 돌아갑니다. 모든 터미널은 **프로젝트**에 속합니다. 프로젝트는 한 번 등록해 두는 내 컴퓨터의 폴더입니다. 그래서 폴더를 등록하기 전에는 아무것도 열리지 않습니다.

## 1. HERA 설치

[Releases](https://github.com/jysvai/JYSV-HERA/releases/latest) 에서 내 컴퓨터에 맞는 파일을 받아 설치하세요. 어떤 파일을 받을지는 [설치](../../README.ko.md#설치) 표에 있습니다.

- **Windows:** 아직 코드 서명이 없어서 파란색 "Windows의 PC 보호" 창이 뜰 수 있습니다. *추가 정보* 를 누른 뒤 *실행* 을 누르세요. 관리자 권한은 필요 없습니다.
- **macOS:** `.dmg` 를 열고 HERA 를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 실행은 macOS 가 막습니다. macOS 15 이상은 *시스템 설정 → 개인정보 보호 및 보안* 에서 **그래도 열기** 를 누르세요. macOS 12–14 는 앱을 우클릭한 뒤 *열기* 를 고르세요.

화면 언어는 컴퓨터 언어(한국어 또는 영어)를 따릅니다. 바꾸려면 *설정 → 화면 언어* (언어 · Language) 에서 고르세요.

## 2. AI 도구 하나 이상 설치

HERA 는 컴퓨터에 이미 설치된 AI 도구를 찾아서 보여 줍니다. 지금 하나를 설치하세요. 나머지는 나중에 더해도 됩니다.

| AI | 설치 (터미널에 붙여 넣기) | 필요한 계정 |
|---|---|---|
| [Claude Code](https://claude.com/claude-code) | `npm i -g @anthropic-ai/claude-code` | Claude Pro 또는 Max, 또는 API 키 |
| [Codex](https://github.com/openai/codex) | `npm i -g @openai/codex` | ChatGPT 요금제, 또는 API 키 |

- `npm` 은 [Node.js](https://nodejs.org/) 를 설치하면 같이 깔립니다. 터미널에서 `npm` 을 찾을 수 없다고 나오면 Node.js **LTS** 버전부터 설치하세요.
- 명령은 아무 터미널에서나 실행하면 됩니다. Windows 는 PowerShell, macOS 는 터미널 앱입니다. 3단계를 마친 뒤에는 HERA 터미널에서도 됩니다.
- **설치한 뒤에는 HERA 를 완전히 종료했다가 다시 켜세요.** 창을 닫으면 HERA 는 트레이(시계 옆, macOS 는 메뉴 막대)로 숨기만 합니다. 트레이 아이콘을 우클릭해서 *종료* 를 누르세요. HERA 는 시작할 때 PATH 를 읽기 때문에, 그 뒤에 설치한 도구는 다시 켜야 보입니다.

HERA 는 AI 도구 32종을 알고 있습니다. **에이전트** 페이지에 도구마다 설치 명령이 나와 있습니다.

## 3. 프로젝트 폴더 등록

프로젝트는 그냥 작업할 파일을 두는 폴더입니다. 아직 없다면 빈 폴더를 하나 만드세요. 예: `문서/my-first-project`

그다음 아래 중 하나를 하세요.

- 탐색기나 Finder 에서 폴더를 HERA 왼쪽 사이드바로 끌어다 놓기
- **폴더 추가** 를 눌러 고르기
- **상위 폴더에서 찾기** 를 눌러 `바탕화면` 같은 폴더를 고른 뒤, HERA 가 찾은 프로젝트에 체크하기

사이드바에 폴더가 나타납니다. HERA 는 폴더 위치만 기억하고, 폴더 안의 파일은 건드리지 않습니다.

## 4. 터미널이나 AI 열기

사이드바에서 프로젝트를 누르면 시작 화면이 나옵니다.

- **터미널**: 그 폴더에서 여는 일반 명령줄
- 설치된 AI 마다 하나씩 있는 카드. 예: **Claude Code**. 누르면 그 폴더에서 AI 가 시작됩니다.

쓰려는 AI 카드가 없다면 HERA 가 아직 그 도구를 못 찾은 것입니다. 2단계로 돌아가서 HERA 를 다시 켜세요.

## 5. AI 를 처음 실행할 때

AI 도구는 처음 한 번 몇 가지를 묻습니다.

- **로그인.** Claude Code 와 Codex 는 브라우저를 열어 로그인하게 합니다. 돈을 내는 계정(예: Claude Max, ChatGPT Plus)으로 로그인하세요. 로그인 정보는 AI 도구가 가지고 있고, HERA 는 보지 않습니다.
- **이 폴더를 믿나요?** AI 가 이 폴더의 파일을 읽고 바꿔도 되는지 묻습니다. 내 프로젝트라면 "예" 를 고르세요.
- 그다음 하고 싶은 일을 평소 말투로 적고 Enter 를 누르세요. 예: *"이 폴더에 간단한 할 일 웹 페이지 만들어 줘"*

AI 가 명령 실행이나 파일 수정 같은 허락을 구하면, HERA 는 탭에 **승인 대기** 를 표시하고 알림을 보낼 수 있습니다. 질문을 읽고 터미널에서 답하세요.

## 6. 다음 단계

- **AI 여러 개 같이 쓰기:** AI 를 하나 더 연 뒤, 터미널 위의 **분할 전환** 버튼을 누르면 나란히 보입니다.
- **서로 일하게 하기:** 오른쪽 **백로그** 에 할 일을 추가하고 ▶ → *멀티 에이전트로 진행* 을 누르세요. AI 하나가 리드를 맡아 나머지에게 일을 나눠 줍니다. [에이전트](agents.md#hera-를-치지-않는-멀티-에이전트-작업) 참고.
- **한도 보기:** 오른쪽 *사용량* 탭에 AI 별로 한도를 얼마나 썼는지 나옵니다. [사용량](usage.md) 참고.
- **닫기:** 창을 닫아도 트레이에서 모두 계속 돌고, 재부팅해도 탭이 돌아옵니다. [세션 기억](session-memory.md) 참고.

## 잘 안 될 때

| 보이는 것 | 해결 |
|---|---|
| 화면에 "프로젝트를 등록하세요" 만 나오고 터미널이 안 열림 | 터미널은 프로젝트 안에서 열립니다. 폴더를 등록하고(3단계) 사이드바에서 누르세요. |
| Claude Code (또는 다른 AI) 카드가 없음 | 설치가 안 됐거나, HERA 를 켠 뒤에 설치했습니다. 설치하고(2단계) 트레이에서 HERA 를 종료한 뒤 다시 켜세요. |
| HERA 터미널에서 `claude` 를 치면 찾을 수 없다고 나옴 | 원인이 같습니다. 트레이에서 HERA 를 종료하고 다시 켜세요. 도구가 어디 있는지는 `where claude` (Windows) 나 `which claude` (macOS, Linux) 로 확인합니다. |
| `npm` 을 찾을 수 없다고 나옴 | Node.js 가 없습니다. [nodejs.org](https://nodejs.org/) 에서 LTS 버전을 설치하고 HERA 를 종료했다가 다시 켜세요. |
| AI 가 매번 로그인하라고 함 | 브라우저 로그인을 한 번 끝까지 마치세요. Codex 는 [문제 해결](troubleshooting.md#hera-를-재시작하면-codex-가-다시-로그인하라고-할-때) 을 보세요. |

다른 문제: [문제 해결](troubleshooting.md)
