# 테마

<img src="../images/features/themes.jpg" alt="" width="120" align="right">

사이드바의 **테마 · 색상** 을 엽니다. 바꾸면 바로 적용됩니다. 제목 표시줄의 ☀/☾ 버튼으로 언제든 라이트와 다크를 바꿀 수 있습니다.

## 밝기

**다크**, **라이트**, **시스템 따라가기**.

## 프리셋

기본 제공 테마 9개:

| 다크 | 라이트 |
|---|---|
| HERA 다크 | HERA 라이트 |
| HERA 딤 (밝은 다크) | 화이트 |
| 미드나잇 | 세피아 (눈 편한) |
| 그라파이트 | 스카이 |
| 오로라 | |

HERA 는 라이트용과 다크용 선택을 하나씩 따로 기억합니다 (“라이트 테마 · …”, “다크 테마 · …”). 테마를 고르면 그 테마의 밝기로 바뀝니다. 단, 밝기가 시스템 따라가기면 바뀌지 않고, 해당 밝기일 때 그 테마가 쓰입니다.

## 강조색

색상 12개, 직접 고르는 색상 선택기 (“강조색 직접 고르기”), 테마 자체의 강조색으로 되돌리는 “테마 기본”. 여기서 고른 강조색은 내 색상의 강조색보다 우선합니다.

## 읽기 편하게

- **글자 선명하게**: 글자와 테두리 대비를 높입니다.
- 터미널 글자 크기 −/+ (8 ~ 28). 설정의 글자 크기와 같은 값입니다.

## 내 색상 만들기

**지금 테마를 복제해서 만들기** 를 누르면 쓰고 있는 테마를 복사한 “<이름> 사본” 이 만들어지고, 이를 고칠 수 있습니다.

- 이름 (최대 40자). 배지로 라이트인지 다크인지 보입니다.
- 화면 각 부분의 색: 색 선택기와 16진수 입력.
- 터미널의 배경 · 글자 · 커서 · 선택 영역과 ANSI 16색.

고치는 동안 바로 미리 보이고, 멈춘 뒤 350 ms 후 저장됩니다. **삭제** 하면 테마가 지워지고, 쓰고 있던 것이면 HERA 다크 또는 HERA 라이트로 돌아갑니다.

## Windows Terminal 의 색 가져오기

Windows 에서는 설정 → 터미널에서 Windows Terminal 기본 프로필의 색 구성을 “<구성 이름> (WT)” 라는 내 색상으로 가져올 수 있습니다. `settings.json` 에 직접 만든 구성과 Windows Terminal 기본 구성(Campbell, One Half, Solarized, Tango, Vintage 등)을 읽습니다. 구성에 ANSI 16색과 배경 · 글자색이 모두 `#RRGGBB` 로 있어야 합니다. [터미널](terminal.md#windows-terminal-에서-가져오기) 참고.
