# JYSV HERA 0.2.6 — 2026-10-28

영어 화면에서 보이던 문제를 고쳤고, 화면 밖으로 넘치던 메뉴를 바로잡았고, 처음 시작하기 안내에 그림을 넣었습니다.

### 고친 것

- **한국어 Windows 에서 영어 화면을 쓰면 날짜가 "2026. 10. 28. 오후 3:14" 로 나오던 문제.** 이제 날짜와 시간이 화면 언어를 따릅니다. 백로그 패널, 프롬프트 기록, 에이전트 대화, 사용량 초기화 시각, 복원된 세션에 적용됩니다.
- **영어 화면의 에이전트 페이지에서 팀 프리셋 이름이 한국어로 남던 문제.** 다른 화면처럼 번역됩니다.
- **창 아래쪽 메뉴가 화면 밖으로 넘치던 문제.** 예를 들어 백로그 아래쪽에 있는 할 일의 멀티 에이전트 메뉴가 잘렸습니다. 이제 버튼 아래에 공간이 없으면 메뉴가 위로 펼쳐집니다.

### 문서

- [처음 시작하기](../../ko/getting-started.md) 를 그림 중심으로 바꿨습니다.
  - 번호를 붙인 실제 화면: 처음 켠 화면, 프로젝트 시작 화면, 에이전트 페이지, 승인을 기다리는 AI, 분할 화면, 백로그에서 멀티 에이전트로 진행하기
  - 설명 그림: HERA 가 동작하는 방식, Windows SmartScreen 경고 넘기기, 트레이에서 종료하기
  - 새로 넣은 안내: 터미널 여는 법, Node.js 설치 뒤 터미널 다시 열기, PowerShell 스크립트 정책, 받을 파일 고르기, 탭 점 색의 뜻
- README 의 처음 쓰기에 HERA 가 동작하는 방식을 그림 한 장으로 넣었습니다.
