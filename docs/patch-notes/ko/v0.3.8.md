# JYSV HERA 0.3.8 — 2026-11-11

lane 은 이제 메인 Claude 만 열고, HERA 가 inline lane 을 알아봅니다.

### 바꾼 것

- **HERA 가 lane 을 직접 열지 않습니다.** Lanes 패널의 여는 버튼(▶, “모두 열기”)과 “Claude 를 열면 lanes 도 같이 열기” 설정을 뺐습니다. 메인 Claude 가 닫힌 lane 에 일을 넘길 때 이미 lane 을 직접 열기 때문에, HERA 가 따로 연 lane 은 일을 기다리기만 했습니다. inline lane 일 때는 일을 아예 받지 못했습니다. 자기 세션으로 도는 lane 의 닫기 버튼은 그대로 있습니다.

### 추가한 것

- **inline lane (lanes 0.4.0).** Lanes 설정의 “lane 여는 방식” 에 inline 이 생겼습니다. lane 이 메인 Claude 세션 안의 팀원이 되어 프롬프트 아래 에이전트 패널에 보이고, 탭도 창도 Claude 프로세스도 늘지 않습니다. inline 은 에이전트 팀이 켜져 있어야 하고, 꺼져 있으면 설정 페이지에 켜는 방법이 나옵니다. 설정 방식을 자동으로 바꿔도 inline 은 그대로 둡니다.

### 고친 것

- **inline lane 이 “꺼짐” 으로 보이던 문제.** HERA 는 lane 세션만 찾았는데 inline lane 에는 세션이 없습니다. 이제 이끄는 메인 세션이 살아 있는 동안 “대기” 나 “작업 중” 으로 보이고, “메인의 팀원” 표시가 붙습니다. 메인 Claude 의 `/lane stop` 으로만 닫을 수 있어서 닫기 버튼이 없고, “모두 닫기” 는 이 lane 을 건드리지 않고 그 사실을 알려 줍니다.
- **자동 설정이 HERA 에서 Claude 를 열 때 `dontAsk` 허용 목록을 넣습니다.** 예전에는 HERA 가 lane 을 열 때만 넣었는데, 이제 HERA 는 lane 을 열지 않습니다. HERA 가 읽지 못하는 프로젝트 `settings.local.json` 은 덮어쓰지 않고 그대로 둡니다.
- **lanes 0.3.13 보다 오래된 버전인데도 Lanes 페이지가 Windows 에서는 HERA 탭으로 열린다고 안내하던 문제.** 그 버전은 HERA 에 탭을 요청하지 못하므로, 이제 업데이트하라고 안내합니다.
