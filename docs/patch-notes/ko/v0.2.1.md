# JYSV HERA 0.2.1 — 2026-10-27

오류 수정과 호환성 릴리스입니다. 터미널이 Windows Terminal 처럼 동작하고, lanes 가 HERA 밖으로 나가지 않습니다.

### 고친 것

- **전체 화면 프로그램에서 마우스 휠.** Windows 에 들어 있는 콘솔 엔진이 전체 화면 프로그램의 마우스 요청을 삼켜서, Claude Code 전체 화면 모드 · vim · htop 에서 휠이 위아래 화살표 키로 들어갔습니다. 이제 Windows Terminal 의 콘솔 엔진(ConPTY 1.23)을 함께 넣어 휠로 스크롤됩니다. *설정 → 터미널 → 최신 ConPTY 사용* 을 끄면 Windows 기본 엔진으로 돌아갑니다.
- **탭을 바꾸면 스크롤이 막히던 문제.** 탭을 다시 보여 줄 때 화면을 복원하면서 마우스 형식(SGR), 커서 표시 · 모양, 스크롤 영역을 빠뜨렸습니다. 이제 모두 복원합니다.
- **탭 전환 · 크기 조절 뒤 화면이 깨지던 문제.** 뒤에서 화면을 기록하는 터미널이 이모지 폭과 ConPTY 크기 조절을 보이는 터미널과 다르게 처리했습니다. 이제 둘 다 Unicode 11 폭과 같은 ConPTY 규칙을 씁니다. 탭을 바꿔도 스크롤 기록이 1,500줄로 잘리지 않고, 터미널이 보여 주는 만큼(최대 5,000줄) 돌아옵니다.
- **스크롤해야 고쳐지던 화면.** 복원한 화면이 다 들어오면 모든 줄을 한 번 다시 그립니다.
- **붙여넣기가 두 번 되던 문제.** Ctrl+V 를 HERA 가 한 번, 브라우저 기본 붙여넣기가 한 번 더 처리했습니다.
- **크기 조절 폭주.** 창이나 분할선을 끄는 동안 매 프레임 크기를 보내지 않고, 멈춘 뒤 80ms 에 한 번 보냅니다.
- **화면에 안 보이는 탭이 시작되지 않던 문제.** 새 콘솔 엔진은 셸을 시작하기 전에 터미널의 응답을 기다립니다. 화면에 없는 탭도 이제 응답합니다.
- **재시작 뒤 lanes 회신이 사라지던 문제.** HERA 가 메인 Claude 탭에 그 폴더의 가장 최근 대화를 붙였는데, 그게 lane 의 대화일 수 있었습니다. 그래서 재시작 뒤 메인 탭이 lane 대화를 이어 열고 진짜 메인 세션은 돌아오지 않아, lane 의 회신이 갈 곳을 잃었습니다. 이제 lane 대화는 메인 탭에서 절대 이어 열지 않고, 탭은 HERA 가 시작한 대화를 지키며, lane 탭은 lanes 가 다시 엽니다.

### 추가한 것

- **누가 열든 lanes 는 HERA 탭으로.** 전에는 HERA 의 Lanes 화면에서 연 lane 만 탭이 됐고, 메인 세션이 스스로 연 lane(닫힌 lane 에 일을 넘길 때, `/lane start`, 재시작)은 별도 PowerShell 창으로 열렸습니다. lanes 0.3.13 부터는 모든 lane 이 `hera host --lane` 으로 HERA 에 탭을 요청합니다. HERA 는 등록된 프로젝트일 때만 받고, 그 밖의 폴더에서는 예전처럼 창이 따로 열립니다. Windows · macOS · Linux 모두 됩니다.
- **`hera host`.** 폴더가 속한 등록 프로젝트에 명령을 탭으로 엽니다 (`hera host --cwd <폴더> -- npm run dev`). 프로젝트 밖의 폴더는 거절합니다. 스크립트와 도구가 터미널 창을 여는 대신 쓸 수 있습니다.
- **Windows Terminal 설정 가져오기.** *설정 → 터미널* 에 Windows Terminal 기본 프로필에서 가져올 수 있는 것을 보여 줍니다: 글꼴과 크기, 커서 모양, 스크롤백, 기본 셸, 색 구성(테마로 추가). 항목마다 체크해서 고릅니다.
- **어떤 셸이든.** 셸 선택에 이 PC 에 있는 셸(Windows PowerShell, PowerShell 7, cmd, Git Bash, WSL)이 나오고, `wsl.exe -d Ubuntu` 나 `"C:\tools\nu.exe" -l` 같은 명령줄을 그대로 적을 수 있습니다.
- **Windows Terminal 의 글꼴.** Cascadia Mono(SIL OFL 1.1)를 함께 넣어 어느 PC 에서나 같은 글꼴로 보입니다. 글꼴이 준비된 뒤에 터미널을 그립니다.
- **커서 설정.** 세로 막대 · 블록 · 밑줄, 깜빡임.

### 바뀐 것

- 설치 파일에서 node-pty 의 디버그 기호(`.pdb`, 풀었을 때 약 28MB)를 뺐습니다.
- `hera peek` 과 상태 감지가 ConPTY 가 줄 끝에 채우는 공백을 무시합니다.
