# JYSV HERA 0.2.3 — 2026-10-27

HERA 와 AI CLI 를 앱 안에서 업데이트하고, 영어로도 쓸 수 있고, 재시작해도 Codex 로그인이 풀리지 않습니다.

### 고친 것

- **HERA 를 재시작 · 업데이트할 때마다 Codex 가 다시 로그인을 요구하던 문제.** Codex 는 공유 백그라운드 서버(데몬) 하나를 두는데, 이 데몬이 ChatGPT 로그인을 따로 들고 있고 `auth.json` 의 계정이 바뀌면 다시 읽지 않습니다. 데몬이 예전 로그인이나 로그아웃 상태를 들고 있으면, 재시작 뒤 새로 연 Codex 탭이 모두 그 데몬에 붙어 `auth.json` 이 멀쩡한데도 로그인 화면을 띄웠습니다. 이제 HERA 는 Codex 탭을 `--no-daemon` 으로 열어, 탭마다 현재 로그인을 읽습니다. 이 옵션이 없는 예전 Codex 는 전처럼 엽니다. *설정 → 터미널 → Codex 로그인 유지* 로 끌 수 있습니다.
- **macOS: “PATH 에서 찾은 AI CLI 가 없습니다” 와 열리지 않던 lanes.** Dock 이나 Finder 로 켠 앱은 Homebrew · npm · bun · `~/.local/bin` 이 빠진 최소 PATH 를 받아서, 설치된 CLI 를 못 찾고 lanes 도 `claude` 를 찾지 못했습니다. 이제 로그인 셸에 PATH 를 물어 가져옵니다(흔한 설치 폴더도 더함). Linux 데스크톱 실행기도 같이 고쳤습니다.
- **lanes “모두 열기” 가 실패해도 연다고 표시하던 문제.** 이제 lane 이 왜 열리지 않았는지 보여 줍니다.

### 추가한 것

- **앱 안에서 업데이트.** 업데이트 버튼을 누르면 GitHub 릴리스에서 이 OS 용 파일을 받아 GitHub 가 공개한 SHA-256 과 맞춰 보고, 한 번 더 누르면 다시 시작해서 새 버전으로 바뀝니다. 터미널은 세션 기억으로 돌아옵니다. Windows 설치본(사용자 · 모든 사용자), macOS 앱, AppImage, deb, rpm 이 그 자리에서 업데이트되고, 휴대용 zip 과 tar.gz 는 전처럼 릴리스 페이지를 엽니다.
- **확장 · 업데이트 페이지.** *에이전트 → 확장 · 업데이트* (또는 *설정 → 버전 · 업데이트*) 에서 AI CLI 와 전역 도구의 설치된 버전과 최신 버전(npm · Homebrew · uv · pipx, 또는 CLI 자체 `update`)을 보고, 각 CLI 에 설치된 것들도 한곳에서 봅니다: Claude Code 플러그인 · MCP 서버 · 스킬, Codex 플러그인 · MCP · 스킬, Gemini CLI · Qwen 확장, OpenCode 플러그인, Copilot · Cursor · Kiro 등 다른 CLI 의 MCP 서버, `~/.agents/skills` 의 공용 스킬. **업데이트**(하나) 또는 **새 버전 N개 모두 업데이트** 를 누르면 터미널 탭에서 실행되어 진행 상황과 비밀번호 요청을 그대로 볼 수 있습니다. MCP 서버는 이름과 실행하는 패키지 · 호스트만 보여 주고 토큰이나 환경 변수는 표시하지 않습니다.
- **영어 화면.** *설정 → 언어*: 자동(운영체제 언어), 한국어, English.
- **폴더별 프롬프트 기록.** 프롬프트를 보낸 폴더별로 묶어 보여 줍니다(등록한 프로젝트는 하위 폴더까지 포함). 왼쪽에 폴더 목록이 있고, 지금 프로젝트의 폴더가 먼저 열립니다.
- **폴더 트리.** 오른쪽 패널의 **폴더** 탭(`Ctrl+Shift+E`, `⌘E`)에 프로젝트 파일이 git 변경 표시와 함께 나옵니다. 더블클릭하면 파일이 열리고, 버튼으로 경로를 터미널에 넣거나 복사하거나 탐색기 · Finder 에서 보고, 항목을 터미널로 끌어다 놓으면 경로가 입력됩니다.
- **폴더를 끌어다 놓아 프로젝트 등록.** 탐색기나 Finder 에서 폴더 여러 개를 프로젝트 사이드바에 놓으면 됩니다.
- **터미널 확대 · 축소.** `Ctrl` + `+` / `-` / `0` (macOS 는 `⌘`), 또는 `Ctrl` / `⌘` + 마우스 휠(트랙패드 핀치)로 터미널 글자 크기를 바꿉니다. `0` 은 설정한 크기로 되돌립니다.
- **새 앱 아이콘:** 작은 왕관을 얹은 금빛 터미널 프롬프트(`>_`).
