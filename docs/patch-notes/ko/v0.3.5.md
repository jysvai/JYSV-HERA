# JYSV HERA 0.3.5 — 2026-11-02

이어하기로 연 Claude·Codex 탭도 *진행 중* 에 나옵니다.

### 고친 것

- **이어하기로 연 탭이 *진행 중* 에 나오지 않던 문제.** 이어하기(`claude --continue`, `codex resume --last`)는 새 대화 파일을 만들지 않고 이전 대화 파일에 이어서 씁니다. HERA 는 탭이 열린 뒤에 생긴 대화 파일만 그 탭의 것으로 보아서, 이런 탭은 일을 해도 *지금 일하는 에이전트 없음* 으로 나왔습니다. 이제 다른 탭이 맡지 않은 대화 중 탭이 열린 뒤에 기록된 것을 그 탭의 대화로 찾습니다. 다른 탭의 대화나 lane 의 대화는 가져가지 않습니다.
- **이어하기로 연 탭이 HERA 를 다시 켜면 새 대화로 시작하던 문제.** 같은 이유로 HERA 가 그 탭의 대화를 몰라서, 재시작 뒤 자동 복원 때 빈 대화로 열렸습니다. 이제 대화를 기억하므로 같은 대화로 정확히 이어집니다.
- Bedrock 의 inference profile ARN 처럼 긴 모델 이름은 마지막 부분만 보여 줍니다.
