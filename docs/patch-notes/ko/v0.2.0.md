# JYSV HERA 0.2.0 — 2026-10-27

**JYSV HERA** 의 첫 공개 릴리스입니다. AI 코딩 CLI 를 위한 가벼운 프로젝트 터미널 · 지휘소로, Windows · macOS · Linux 를 지원합니다.

- **주요 기능:**
  - 프로젝트 런처와 탭 · 분할 작업공간, 실시간 상태와 알림.
  - AI CLI 32종 내장: Claude Code, Codex, Antigravity, Grok, Meta Muse, Mistral Vibe, Kiro 등.
  - AI 끼리 일을 넘기는 `hera` CLI.
  - 재부팅 후 대화 그대로 이어 가는 세션 기억.
  - 사용량 · 한도, lanes 연동, 테마.
  - 사이드바의 버전 태그와 새 버전 알림. 설정에서 끌 수 있으며, HERA 의 유일한 네트워크 요청입니다.
