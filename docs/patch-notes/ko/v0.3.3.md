# JYSV HERA 0.3.3 — 2026-10-30

새 PC 에서도 lane 이 HERA 탭으로 열립니다.

### 고친 것

- **새 PC 에서 lane 이 HERA 탭이 아니라 별도 창으로 열리던 문제.** HERA 는 *설정 → Lanes → HERA 에서 lanes 사용* 이 켜져 있을 때만 lanes 에게 탭을 쓰라고 알렸는데, 이 스위치는 설치 직후 꺼져 있습니다. 이제 *HERA 에서 lane 을 열 때*(기본값 **HERA 탭**)만으로 정하고, 이 항목은 스위치가 꺼져 있어도 보이도록 연동 섹션으로 옮겼습니다. 업데이트한 뒤 새로 여는 터미널부터 적용됩니다. [Lanes](../../ko/lanes.md) 참고.
- **Windows: HERA 가 받지 못한 lane 이 아무 데도 열리지 않던 문제.** HERA 가 거절해도 `hera` 명령이 성공으로 끝나서, lanes 가 자기 창을 여는 대신 오지 않을 탭을 기다렸습니다. 이제 `hera` 가 실제 결과를 그대로 돌려줍니다.
- **HERA 가 lane 을 받지 못할 때 이유가 나오지 않던 문제.** HERA 프로젝트가 아닌 폴더에서 Claude 가 돌면, 이제 lane 을 별도 창으로 연다는 것과 그 폴더를 프로젝트로 추가하면 된다는 알림이 나옵니다.
- 설치된 lanes 플러그인이 메인 Claude 가 연 lane 을 HERA 탭으로 열기에 너무 오래됐으면(0.3.13 이전) Lanes 페이지에 알려 줍니다.

### 문서

- Lanes 와 문제 해결 문서에 새 설정과, lane 이 별도 창으로 열릴 때 확인할 것을 적었습니다.
