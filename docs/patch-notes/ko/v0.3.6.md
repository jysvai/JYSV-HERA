# JYSV HERA 0.3.6 — 2026-11-02

탭 여러 개를 한꺼번에 닫아도 HERA 가 꺼지지 않습니다.

### 고친 것

- **Windows: 터미널 여러 개가 거의 동시에 닫힐 때 HERA 가 가끔 통째로 꺼지던 문제.** 작업 공간을 지울 때처럼 탭 여러 개가 한꺼번에 닫히면, 터미널 라이브러리(node-pty)의 동시 처리 버그 때문에 약 5% 확률로 HERA 가 아무 메시지 없이 종료됐습니다. 이 버그가 고쳐진 node-pty 1.2.0 베타(1.2.0-beta.18)로 올렸고, 같은 조건 120번 반복에서 한 번도 꺼지지 않았습니다(이전 버전은 10번). 거기에 더해, 이제 터미널을 실제로 닫는 일을 하나씩 조금 간격을 두고 합니다. 탭은 누르는 즉시 사라집니다.
