# JYSV HERA 0.3.9 — 2026-11-11

Claude 를 폰에서 이어 가고 다시 컴퓨터로 가져오고, AI 가 무엇을 바꿨고 어디에 영향이 있는지 봅니다.

### 더한 것

- **Claude 를 폰 · 웹에서도 이어 하기 (Remote Control).** *설정 → 터미널 → Claude 를 폰 · 웹에서도 이어 하기* 를 켜면 HERA 가 여는 Claude 탭이 Claude 앱의 **Code** 탭과 claude.ai/code 에 프로젝트 이름으로 뜹니다. 어느 쪽에서 입력해도 같은 세션에서 대화가 이어집니다. Claude Code 는 Anthropic 의 배포 설정이 허락한 곳에서만 Remote Control 을 스스로 켜서 폰에 세션이 안 보이게 될 수 있었는데, 이제 HERA 가 명령줄에서 직접 켭니다. 설정은 탭이 시작될 때마다 읽으므로 ▶ 와 복원된 탭도 따라갑니다. [안내](../../ko/remote-control.md)
- **폰에서 이 컴퓨터로 세션 시작.** 프로젝트 시작 화면의 *폰 · 웹에서 이어 하기* 에서 **폰에서 이 프로젝트로 새 세션 시작** 을 켜세요. HERA 가 실행되는 동안 그 폴더에 `claude remote-control` 서버를 띄워 두고, 폰에서 거기로 새 세션을 시작할 수 있습니다. 패널에 서버 연결 상태가 나오고, claude.ai/code 링크를 복사할 수 있고, 서버 오류와 **다시 시도** 가 나옵니다. claude.ai 로 로그인되어 있으면 환경에 `ANTHROPIC_API_KEY` 가 있어도 서버가 뜹니다(원래는 서버 모드가 시작을 거부합니다). HERA 는 종료할 때 서버를 Ctrl+C 로 멈추므로 폴더가 바로 풀립니다.
- **폰 · 웹 세션을 HERA 탭으로 가져오기.** **폰 · 웹 세션 가져오기** (시작 화면과 **+** 메뉴)는 `claude --teleport` 를 열어 이 저장소의 폰 · Remote Control · 클라우드 세션 목록을 보여 줍니다. 고른 세션은 HERA 탭에서 이어집니다.
- **무엇이 바뀌었고 어디에 영향이 있나.** *진행 중* 에 **바뀐 파일** 카드가 생겨 지금 작업이 더하고 지운 파일 수와 줄 수를 보여 줍니다. 카드나 바뀐 파일을 누르면 에이전트마다 바꾼 내용을 줄 단위로, 그리고 그 파일의 **영향 범위**(그 파일을 import 하는 파일, 그 파일들을 거쳐 닿는 파일, 관련 테스트)를 봅니다. 메모 칸으로 그 변경을 한 에이전트에게 의견을 보낼 수 있고, **확인 요청** 은 돌릴 테스트와 확인할 파일을 메모에 채워 줍니다. 바뀐 내용은 Claude Code 와 Codex 가 직접 남긴 수정에서, 영향 범위는 TypeScript · JavaScript · Python 의 import 에서 찾습니다.
