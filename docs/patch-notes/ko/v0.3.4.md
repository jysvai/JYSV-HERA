# JYSV HERA 0.3.4 — 2026-11-01

터미널을 하나하나 읽지 않아도 AI 가 지금 무엇을 하는지 보입니다.

### 새 기능

- **폴더 탭의 실시간 작업 현황.** 프로젝트에서 AI 가 일하는 동안 폴더 트리 위 **진행 중** 영역에 이런 것이 나옵니다.
  - 에이전트별 진행률: 스스로 만든 할 일 목록이나 계획 기준(둘 다 없으면 띄운 서브에이전트 중 끝난 수), 맡긴 요청, 지금 하는 단계;
  - 모델별 작업량(Opus, Sonnet, Haiku, gpt 등)과 API 정가로 환산한 예상 비용;
  - Claude Code 가 띄운 서브에이전트의 종류 · 모델 · 맡은 일;
  - 어느 에이전트가 어떤 파일을 **보고**(파랑) **고치는지**(주황). 두 에이전트가 같은 파일을 고치면 **빨갛게** 바뀝니다. 파일을 누르면 폴더 트리가 그 파일로 열리고, 트리에도 같은 표시가 붙습니다.

  패널에서 다른 탭을 보고 있어도 폴더 탭 옆 점으로 에이전트가 일하는 중인지 알 수 있습니다. Claude Code(서브에이전트 · lanes 포함)와 Codex 를 지원하고, 이들이 원래 컴퓨터에 남기는 기록을 읽습니다. 설치할 것도, 밖으로 보내는 것도 없습니다. [실시간 작업 현황](../../ko/live-activity.md) 참고.

### 고친 것

- 막 시작한 Codex 탭이 몇 초 안에 자기 대화와 연결됩니다(최대 30초쯤 걸릴 수 있었습니다). 재시작 후 정확한 대화 이어가기도 그만큼 빨리 알아챕니다.
