# JYSV HERA 0.2.5 — 2026-10-28

보안 업데이트입니다. Electron 을 지원 중인 버전으로 올렸고, CodeQL 이 찾은 문제를 앱에서 고쳤고, macOS 에서 스크린샷을 붙여넣으면 이미지가 한 장만 붙습니다.

### 보안

- **Electron 40 → 44.10.0.** Electron 40 은 더 이상 보안 수정을 받지 못합니다. 44 는 Chromium 152 를 쓰고 Electron 보안 권고 14건을 해결합니다. 샌드박스 페이지에서 연 창 · 팝업이 제한을 벗어나던 문제, 권한 요청이 엉뚱한 출처로 잡히던 문제, 유출된 eMudhra 중간 인증서 문제 등입니다.
- **CodeQL 이 찾은 문제를 앱에서 수정.** 세션 · 메시지 id 를 암호학적 난수로 만듭니다. 붙여넣은 스크린샷은 내 계정만 열 수 있는 폴더에 저장하고, 이미 있는 파일이나 링크를 통해서는 절대 쓰지 않습니다. lanes 설정 파일을 읽고 쓰는 사이의 경쟁 조건을 없앴습니다. 따옴표 · 퍼센트 · 줄바꿈 문자가 든 Windows `.cmd` 경로와 인자는 셸에 넘기기 전에 거부합니다.
- **개발 도구.** Vite 8.3.5 와 새 Electron 설치 방식으로 `extract-zip`, `launch-editor` 보안 경고가 사라졌습니다. 둘 다 앱에는 들어가지 않습니다.

### 고친 것

- **macOS 에서 스크린샷을 붙여넣으면 두 장이 붙던 문제** (Claude Code 에서 `[Image #1] [Image #2]`). 이제 HERA 만 붙여넣기를 처리합니다.

### 바뀐 것

- **macOS 13 이상이 필요합니다.** Electron 44 가 macOS 12 지원을 끝냈습니다. Windows 와 Linux 요구 사항은 그대로입니다.
