# JYSV HERA 0.3.2 — 2026-10-30

Codex 탭의 스크롤이 부드러워지고, 붙여넣은 스크린샷이 WSL · SSH 탭에서도 동작합니다.

### 고친 것

- **Codex 탭에서 스크롤이 느리고, macOS 트랙패드로는 조금씩만 움직이던 문제.** Codex 는 전체 화면 모드에서 마우스를 직접 받기 때문에, 휠을 한 칸 굴릴 때마다 Codex 를 거쳐 화면을 다시 그렸습니다. 이제 Codex 탭을 `--no-alt-screen` 으로 엽니다(이 옵션이 있는 Codex 일 때). 대화가 터미널 스크롤백에 남아 다른 탭처럼 스크롤되고, 드래그로 바로 선택 · 복사됩니다. *설정 → 터미널 → Codex 부드러운 스크롤* 로 끌 수 있습니다. [에이전트 → Codex 스크롤](../../ko/agents.md#codex-스크롤) 참고.
- **WSL 탭에 붙여넣은 스크린샷을 그 안에서 열 수 없던 문제.** `C:\Users\…` 경로가 들어가서 Linux 프로그램이 읽지 못했습니다. 이제 붙여넣은 이미지, 끌어다 놓은 파일, 폴더 트리에서 넣은 경로가 WSL 경로(`/mnt/c/Users/…`)로 들어갑니다.

### 새로 생긴 것

- **SSH 탭에 스크린샷 붙여넣기 · 파일 끌어다 놓기.** `ssh` 로 접속한 탭에서는 HERA 가 같은 `ssh` 와 로그인 옵션으로 파일을 그 서버에 먼저 올리고, 서버 쪽 경로(`~/.cache/hera-paste/…`)를 넣습니다. 서버에서 도는 AI CLI 가 그 이미지를 열 수 있습니다. 비밀번호는 묻지도, 대신 입력하지도 않습니다. ssh 키나 ssh-agent 로 동작하고, 서버가 비밀번호를 원하면 아무것도 올리지 않고 알림에 이유가 나옵니다. 뒤에서 도는 것은 없습니다. *설정 → 터미널 → SSH 탭에 이미지 · 파일 올리기* 로 끌 수 있습니다. [터미널 → WSL · SSH 탭](../../ko/terminal.md#wsl--ssh-탭) 참고.
- **무엇을 붙여넣었는지 보입니다.** 이미지를 붙여넣으면 알림에 작은 미리보기와 크기, 올린 서버가 나옵니다.
- **브라우저에서 끌어온 이미지**도 스크린샷처럼 붙여넣어집니다. HERA 는 아무것도 내려받지 않으므로, 브라우저가 웹 주소로만 넘기는 이미지는 복사해서 붙여넣으라고 알려 줍니다.

### 문서

- 터미널 안내에 *WSL · SSH 탭* 절을 새로 넣고, 스크린샷을 이 컴퓨터와 SSH 탭에 붙여넣는 GIF 를 넣었습니다. 업데이트와 개인정보, 보안 문서에 HERA 가 내 `ssh` 를 언제 쓰는지 적었습니다. 문제 해결에 SSH 올리기 실패와 Codex 스크롤을 더했습니다.
