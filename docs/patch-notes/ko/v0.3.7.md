# JYSV HERA 0.3.7 — 2026-11-10

사용량 숫자가 밀리지 않고, 응답마다 한 번씩만 세며, Antigravity 도 함께 집계합니다.

### 추가한 것

- **Antigravity 토큰 사용량.** Antigravity 가 내 컴퓨터에 남기는 대화 기록을 읽어, Claude Code·Codex 처럼 날짜별·폴더별 토큰을 보여 줍니다. 기록에 모델 이름이 없어 사용량은 `Antigravity` 한 줄로 나오고, 남은 한도와 비용도 기록에 없어 표시하지 않습니다. Antigravity 는 최근 대화 500개만 남기는데, HERA 가 한 번 센 대화는 지워진 뒤에도 집계에 남습니다. 다만 이번 업데이트 전에 이미 지워진 대화는 복구할 수 없습니다.

### 고친 것

- **기록이 많으면 사용량이 갱신되지 않을 수 있던 문제.** 기록이 42GB인 PC에서 전체 집계에 162초(제한 180초)와 메모리 13.7GB가 들었습니다. 이제 약 43초, 200MB면 끝나고, 제한은 5분으로 늘었으며, 도중에 끊겨도 멈춘 곳부터 이어서 집계합니다.
- **집계에 실패하면 숫자가 사라질 수 있던 문제.** 이제 마지막 숫자를 그대로 보여 주고 다음 갱신 때 다시 시도합니다. 숫자가 10분 넘게 오래되면 사용량 페이지에 안내가 나옵니다.
- **상태바의 한도가 최대 5분 늦던 문제.** 이제 1분마다 갱신하고, 초기화 시각이 지난 한도는 옛 퍼센트로 표시하지 않습니다.
- **Claude Code 숫자가 두 가지로 어긋나던 문제.** 부모 대화를 복사해 시작하는 서브에이전트에서 그 복사분을 다시 셌고, Claude Code 2.1.289·2.1.296 의 서브에이전트에서는 출력 토큰이 대부분 빠질 수 있었습니다. 이제 응답 하나를 모든 기록에 걸쳐 한 번만, 최종 출력 기준으로 셉니다.
- **일부 Codex 세션이 빠지던 문제.** 새 형식의 토큰 기록만 남긴 세션도 이제 집계합니다.
- **작업이 어느 폴더에도 들어가지 않던 문제.** 기록에 폴더가 아직 나오지 않았을 때, 이제 기록이 늘어나는 동안 계속 찾습니다.

업데이트 후 첫 집계는 기록을 처음부터 다시 읽습니다. 기록이 아주 많으면 1분쯤 걸리고, 끝나면 사용량 페이지가 채워집니다.
