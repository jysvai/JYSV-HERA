# JYSV HERA 0.2.3 — 2026-10-27

HERA updates itself and your AI CLIs now, speaks English as well as Korean, and keeps your Codex login across restarts.

### Fixed

- **Codex asked to sign in again after every HERA restart or update.** Codex keeps one shared background server (its daemon) that holds its own copy of the ChatGPT login and does not reload `auth.json` when the account in it changed. Once it held an old or signed-out login, every Codex tab opened after a restart attached to it and showed the login screen, although `auth.json` was fine. HERA now starts its Codex tabs with `--no-daemon`, so each tab reads the current login. Codex builds without that flag are started as before. *Settings → Terminal → Keep Codex signed in* turns it off.
- **macOS: "no AI CLI found on PATH" and lanes that never opened.** An app started from the Dock or Finder gets a minimal PATH without Homebrew, npm, bun or `~/.local/bin`, so installed CLIs looked missing and lanes could not find `claude`. HERA now asks your login shell for its PATH (and adds the usual install folders). Linux desktop launchers get the same fix.
- **lanes "open all" said it was opening when it had failed.** The message now shows why a lane did not start.

### Added

- **Update from inside the app.** Press the update button: HERA downloads this OS's package from the GitHub release, checks its SHA-256 against the digest GitHub publishes, and on a second press restarts into the new version. Your terminals come back through session memory. Windows installs (per user or all users), macOS app bundles, AppImage, deb and rpm update in place; the portable zip and tar.gz still open the release page.
- **Extensions & updates page.** *Agents → Extensions & updates* (or *Settings → Version & updates*) lists your AI CLIs and other global tools with the installed and the latest version (npm, Homebrew, uv, pipx, or the CLI's own `update`), and what is plugged into each CLI: Claude Code plugins, MCP servers and skills, Codex plugins / MCP / skills, Gemini CLI and Qwen extensions, OpenCode plugins, Copilot, Cursor, Kiro and other CLIs' MCP servers, and the skills shared in `~/.agents/skills`. **Update** (one item) or **Update all N** runs the update in a terminal tab, so you see its progress and any password prompt. MCP servers show only their name and the package or host, never tokens or environment variables.
- **English UI.** *Settings → Language*: Auto (follows your OS), 한국어 or English.
- **Prompt history by folder.** The prompts are grouped by the folder they were sent in (a registered project takes in its subfolders), with a folder list on the left and the current project's folder opened first.
- **Folder tree.** A **Folders** tab in the right panel (`Ctrl+Shift+E`, `⌘E`) shows the project's files with git changes marked. Double-click opens a file, the buttons insert its path into the terminal, copy it or show it in Explorer / Finder, and an entry dragged onto a terminal is typed as its path.
- **Drag folders in to add projects.** Drop one or more folders from Explorer or Finder onto the project sidebar.
- **Terminal zoom.** `Ctrl` + `+` / `-` / `0` (`⌘` on macOS) or `Ctrl` / `⌘` + mouse wheel (or a trackpad pinch) changes the terminal font size; `0` goes back to your setting.
- **A new app icon:** a gold terminal prompt (`>_`) under a small crown.
