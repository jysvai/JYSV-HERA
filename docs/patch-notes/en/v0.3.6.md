# JYSV HERA 0.3.6 — 2026-11-02

Closing several tabs at once no longer brings HERA down.

### Fixed

- **Windows: HERA sometimes quit outright when several terminals closed almost together.** When tabs closed at once, as they do when you delete a worktree, a concurrency bug in the terminal library (node-pty) made HERA exit without a word about 5% of the time. HERA now uses the node-pty 1.2.0 beta (1.2.0-beta.18), which fixes it: 120 runs of the same case never crashed (against 10 with the old version). As a second guard, terminals are now actually closed one at a time, a moment apart. The tab still goes away the instant you close it.
