# JYSV HERA 0.2.1 — 2026-10-27

A fix-and-compatibility release: terminals now behave like Windows Terminal, and lanes stay inside HERA.

### Fixed

- **Mouse wheel in full-screen programs.** Windows' built-in console engine swallowed the mouse modes that full-screen programs ask for, so in Claude Code's full-screen mode, vim or htop the wheel arrived as arrow keys. HERA now ships Windows Terminal's console engine (ConPTY 1.23) and the wheel scrolls. *Settings → Terminal → Use the latest ConPTY* switches back to the built-in one.
- **Scrolling that stopped after a tab switch.** Showing a tab again rebuilt its screen without the mouse encoding (SGR), cursor visibility, cursor shape and scroll region. They are restored now.
- **Screens that broke after a tab switch or resize.** The background copy of each terminal measured emoji widths and handled ConPTY resizes differently from the visible one. Both now use Unicode 11 widths and the same ConPTY rules. A tab switch also brings back up to 5,000 lines of scrollback, as many as the terminal shows, instead of the last 1,500.
- **Rows that stayed stale until you scrolled.** Every row is repainted once a restored screen is in.
- **Paste typed twice.** Ctrl+V pasted once through HERA and once more through the browser's own paste.
- **Resize storms.** The program's size follows 80 ms after a drag settles, instead of on every frame.
- **Background tabs that never started.** The new console engine waits for an answer from the terminal before the shell starts; a tab that is not on screen now answers too.
- **lanes replies that went nowhere after a restart.** HERA gave the main Claude tab the newest conversation in the folder, which could be a lane's. After a restart the main tab resumed the lane's conversation, the real main session never came back, and lane replies had no one to reach. Lane conversations are never resumed in a main tab now, a tab keeps the conversation HERA started it with, and lane tabs are left to lanes to reopen.

### Added

- **lanes open as HERA tabs, whoever opens them.** Before, only a lane started from HERA's Lanes page became a tab; a lane the main session opened (a task sent to a closed lane, `/lane start`, a restart) opened a separate PowerShell window. With lanes 0.3.13 every lane asks HERA for a tab through `hera host --lane`. HERA agrees only for projects registered in HERA; anywhere else the lane opens its own window as before. Works on Windows, macOS and Linux.
- **`hera host`.** Opens a command as a tab of the registered project that holds a folder (`hera host --cwd <dir> -- npm run dev`), and refuses folders outside your projects. Scripts and tools can use it instead of opening a terminal window.
- **Windows Terminal import.** *Settings → Terminal* shows what HERA can take over from Windows Terminal's default profile: font and size, cursor shape, scrollback, default shell and color scheme (added as a theme). Each item is a checkbox.
- **Any shell.** The shell pickers list the shells this PC has (Windows PowerShell, PowerShell 7, cmd, Git Bash, WSL) and take a full command line, such as `wsl.exe -d Ubuntu` or `"C:\tools\nu.exe" -l`.
- **Windows Terminal's font.** Cascadia Mono ships with HERA (SIL OFL 1.1), so the default font list renders the same on every PC. HERA waits for it before laying out terminals.
- **Cursor settings.** Bar, block or underline, and blinking.

### Changed

- Installers no longer carry node-pty's debug symbols (`.pdb`, about 28 MB unpacked).
- `hera peek` and status detection ignore the trailing spaces ConPTY pads rows with.
