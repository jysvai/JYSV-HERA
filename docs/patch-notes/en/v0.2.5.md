# JYSV HERA 0.2.5 — 2026-10-28

A security update: a current Electron, the CodeQL fixes in the app itself, and a single image when you paste a screenshot on macOS.

### Security

- **Electron 40 → 44.10.0.** Electron 40 no longer receives fixes. 44 brings Chromium 152 and closes 14 Electron advisories, among them windows and popups that could escape a sandboxed page's restrictions, permission requests attributed to the wrong origin, and the compromised eMudhra intermediate certificates.
- **CodeQL findings fixed in the app.** Session and message ids come from a cryptographic random source. Pasted screenshots are written to a folder only your account can open, never through an existing file or link. The lanes settings file is updated without a read-then-write race. Windows `.cmd` paths and arguments that contain quote, percent or line-break characters are refused before a shell sees them.
- **Development tools.** Vite 8.3.5 and the new Electron installer remove the `extract-zip` and `launch-editor` advisories. Neither ships in the app.

### Fixed

- **Pasting a screenshot on macOS attached it twice** (`[Image #1] [Image #2]` in Claude Code). HERA now handles the paste alone.

### Changed

- **macOS 13 or later is required.** Electron 44 no longer supports macOS 12. Windows and Linux requirements are unchanged.

### Docs

- New [Getting started](../../en/getting-started.md) page for people new to terminals: installing a first AI tool, registering a folder (and why nothing opens before you do), the first sign-in, and the problems people hit first.
- The README's *Code signing policy* section, and the macOS 15 first-launch steps (*Privacy & Security → Open Anyway*). The OS badges link to the download page.
