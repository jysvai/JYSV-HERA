# JYSV HERA 0.2.0 — 2026-10-27

The first public release of **JYSV HERA**: a lightweight project terminal and command center for AI coding CLIs, for Windows, macOS and Linux.

### Highlights

- **Project launcher and multi-AI workspace.** Tabs, split view for up to 4, live working / idle / approval status, notifications, backlog panel.
- **32 agent CLIs built in.** Claude Code, Codex, Antigravity, Grok Build, Muse Code (Meta), Mistral Vibe, Kiro, Copilot, Junie, Goose, Cline, Continue, Auggie, Kilo, Qoder, OpenCode, Aider, Hermes Agent, LM Studio and more. They are detected on `PATH`.
- **`hera` CLI.** Agents hand work to each other with `hera ask / send / reply / peek / key / spawn`.
- **Session memory.** Shells come back in their last folder; Claude Code and Codex resume the exact conversation after a reboot.
- **Usage.** 5-hour and weekly limits, tokens and cost per AI and per project.
- **lanes integration.** Run [lanes](https://github.com/jysvai/lanes) mid/low helper sessions in HERA tabs, with model routing, permissions and per-project instructions.
- **Themes.** Dark / light / system, 9 presets and a custom theme editor.
- **Lightweight.** About 170 MB with one terminal and 203 MB with four (Windows, measured), idle CPU near zero. This release trims node-pty's per-terminal worker heap and loads WebGL only on demand.
- **Version tag and update check.** The sidebar shows `v0.2.0` and turns into an update button when a newer release is out. It can be turned off in Settings; it is HERA's only network request.
