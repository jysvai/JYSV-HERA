# JYSV HERA 0.3.1 — 2026-10-29

Worktree fixes, above all the cases where work could be lost, and a [Worktrees guide](../../en/worktrees.md) with moving pictures.

### Fixed

- **Deleting a worktree could lose unmerged commits without a warning.** When its folder had been deleted by hand, or git could not report its state, HERA counted nothing to lose and deleted the branch too. HERA now counts again in the repository right before deleting. If it cannot count, it says the work may be lost.
- **"Delete it?" after a merge did not count what the AI wrote meanwhile.** Files the AI wrote during the merge are now counted too.
- **Merging later work after a squash merge conflicted.** The next merge brings in only what was done since. After a squash, HERA also merges the project's branch into the worktree.
- **A tab whose worktree folder was gone reopened its AI in the project folder,** where it could edit the real project. It now opens a plain terminal there and says why.
- **Merging went wrong when the AI had switched branches inside the worktree.** HERA now says to switch back first.
- **Merging while the AI was still writing took in half-written files.** HERA asks first.
- **A comparison that failed to start left worktrees and tabs behind.** HERA takes them back.
- **The backlog's "last change" kept showing the old commit after a merge.**
- **The merge menu named the old branch** after the project folder's branch was switched in a terminal.
- **git error messages showed the whole command line,** and with git set to another language, changed lines showed as 0.
- **Merging was blocked in projects with commit hooks.** The hooks ran when HERA committed the worktree's leftover changes.
- **A failed create could delete a branch that was there before,** when the names differed only in case.
- **Worktree names that Windows reserves (con, nul, …) could not be created.**
- **A big folder in `.worktreeinclude` froze the window while it copied.**
- **English wording:** the tab said "Worktree", and counts read "1 sessions".
- Fixed four file-read races that CodeQL found.

### Changed

- The Worktrees tab warns when the project folder is not on a branch (detached HEAD).
- The self-test also checks two more cases: deleting a worktree whose folder is gone still asks, and a second squash merge works without taking out other work in the project.
