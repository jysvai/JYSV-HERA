# JYSV HERA 0.3.3 — 2026-10-30

Lanes open as HERA tabs on a new PC too.

### Fixed

- **On a new PC, lanes opened in their own window instead of a HERA tab.** HERA asked lanes to use its tabs only while *Settings → Lanes → Use lanes in HERA* was on, and that switch is off after installing. Now only *When HERA opens a lane* decides (**HERA tab** by default), and it sits in the Integration section where you can see it with the switch off. Terminals you open after updating get the change. See [Lanes](../../en/lanes.md).
- **Windows: a lane HERA could not take could open nowhere.** The `hera` command reported success even when HERA said no, so lanes waited for a tab that never came instead of opening its own window. `hera` now passes on the real result.
- **When HERA could not take a lane, nothing said why.** If Claude runs in a folder that is not a HERA project, a notice now says the lane opens in its own window and that adding the folder as a project fixes it.
- The Lanes page says when the installed lanes plugin is too old (before 0.3.13) to open the lanes the main Claude starts as HERA tabs.
