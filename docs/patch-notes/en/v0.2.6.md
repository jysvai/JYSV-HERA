# JYSV HERA 0.2.6 — 2026-10-28

Fixes for the English window, a menu that no longer runs off the screen, and a Getting started guide with pictures.

### Fixed

- **Dates in an English window on a Korean PC** showed as "2026. 10. 28. 오후 3:14". Dates and times now follow the window language, in the backlog panel, prompt history, agent messages, usage resets and restored sessions.
- **Team preset names on the Agents page** stayed in Korean in an English window. They are translated like everywhere else.
- **A menu near the bottom of the window ran off the screen**, for example the multi-agent menu of a to-do low in the backlog. A menu that does not fit below its button now opens upwards.

### Docs

- [Getting started](../../en/getting-started.md) is now led by pictures: annotated screenshots of the first screen, a project's start screen, the Agents page, an AI waiting for approval, split view and multi-agent work from the backlog, plus drawings of how HERA works, the Windows SmartScreen prompt and quitting from the tray. It also covers opening a terminal, reopening it after installing Node.js, PowerShell's script policy, which file to download, and what the tab dots mean.
- The README's quick start shows how HERA works in one picture.
