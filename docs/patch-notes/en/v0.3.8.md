# JYSV HERA 0.3.8 — 2026-11-11

Lanes now open only from the main Claude, and HERA knows about inline lanes.

### Changed

- **HERA no longer opens lanes itself.** The Lanes panel's open buttons (▶ and "Open all") and the "Open lanes together with Claude" setting are gone. The main Claude already opens a lane when it hands work to one that is closed, so a lane HERA opened by itself only sat waiting. With inline lanes it never got any work at all. Close buttons stay for lanes that run as their own sessions.

### Added

- **Inline lanes (lanes 0.4.0).** "How lanes open" in Lanes settings now offers inline. Each lane is then a teammate inside the main Claude's own session, shown in the agent panel under its prompt, with no extra tab, window or Claude process. Inline needs agent teams; if they are off, the settings page says how to turn them on. Switching the setup mode to Automatic keeps inline.

### Fixed

- **Inline lanes showed as "off".** HERA looked only for lane sessions, and an inline lane has none. The panel now shows it as idle or working, marked "teammate of main", while the main session that leads it is running. It has no close button, because only `/lane stop` in the main Claude can close it; "Close all" leaves it running and says so.
- **Automatic setup now adds the `dontAsk` allow list when HERA opens Claude in a project.** It used to happen only when HERA opened a lane, which it no longer does. A project `settings.local.json` that HERA cannot read is now left as it is instead of being replaced.
- **The Lanes page said lanes open as HERA tabs on Windows even with lanes older than 0.3.13.** Such a version can't ask HERA for a tab, so the page now says to update it.
