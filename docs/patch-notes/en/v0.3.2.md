# JYSV HERA 0.3.2 — 2026-10-30

Smooth scrolling in Codex tabs, and pasted screenshots that work in WSL and SSH tabs.

### Fixed

- **Scrolling in a Codex tab was slow, and a macOS trackpad barely moved it.** Codex draws in a full-screen mode and takes the mouse, so every wheel step went to Codex and back for a redraw. HERA now starts Codex tabs with `--no-alt-screen` (when the installed Codex has it): the conversation stays in the terminal's scrollback, scrolls like any other tab, and a drag selects it for copying. *Settings → Terminal → Smooth Codex scrolling* turns it off. See [Agents → Codex scrolling](../../en/agents.md#codex-scrolling).
- **A screenshot pasted into a WSL tab could not be opened there.** The tab got `C:\Users\…`, which a Linux program cannot read. Pasted images, dropped files and paths inserted from the folder tree now arrive as WSL paths (`/mnt/c/Users/…`).

### New

- **Paste screenshots and drop files into SSH tabs.** In a tab logged in somewhere with `ssh`, HERA copies the file to that server first, with the same `ssh` and login options, and types the server's path (`~/.cache/hera-paste/…`). An AI CLI running on the server can then open the image. It never asks for or types a password: it works with an ssh key or ssh-agent, and when the server wants a password, the notice says why and nothing is copied. Nothing runs in the background. *Settings → Terminal → Copy images and files into SSH tabs* turns it off. See [Terminal → WSL and SSH tabs](../../en/terminal.md#wsl-and-ssh-tabs).
- **See what you pasted.** A notice shows a small preview and the size of a pasted image, and which server it went to.
- **Images dragged out of a browser** are pasted like screenshots. HERA downloads nothing: for an image the browser only gives as a web address, the notice says to copy and paste it.

### Docs

- Terminal: a new section, *WSL and SSH tabs*, with GIFs of pasting a screenshot locally and into an SSH tab. Updates and privacy, and Security, say when HERA uses your `ssh`. Troubleshooting covers a failed SSH copy and slow Codex scrolling.
