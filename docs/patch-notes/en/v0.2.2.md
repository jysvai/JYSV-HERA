# JYSV HERA 0.2.2 — 2026-10-27

Usage numbers that keep themselves current.

### Fixed

- **Usage refreshed only every 10 minutes, or when you pressed refresh.** The status bar asked for usage every 5 minutes, and the answer was cached for the same 5 minutes, measured from the end of the parse. Each ask landed just inside the cache, so it got the old numbers and the real refresh came every 10 minutes. Tokens are now re-parsed at most every 4 minutes, so every 5-minute ask gets fresh numbers.
- **Limit percentages that lagged behind.** The 5-hour and weekly limits of Claude Code and Codex were cached together with the tokens. They are small files the CLIs keep current, so HERA now reads them on every request: the status bar and the usage page show the limit Claude Code reported last.
