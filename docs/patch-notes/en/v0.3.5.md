# JYSV HERA 0.3.5 — 2026-11-02

Claude and Codex tabs opened with Continue show up under *In progress* too.

### Fixed

- **A tab opened with Continue never showed under *In progress*.** Continue (`claude --continue`, `codex resume --last`) does not start a new conversation file; it goes on writing the previous one. HERA only took a conversation file created after the tab opened as that tab's, so such a tab said *No agent at work* however busy it was. Now a conversation no other tab holds that was written after the tab opened is taken as the tab's. Another tab's conversation or a lane's is never taken.
- **A tab opened with Continue came back as a new conversation after restarting HERA.** For the same reason HERA did not know the tab's conversation, so the restore after a restart opened an empty one. HERA now remembers it and resumes exactly that conversation.
- Long model names, such as a Bedrock inference-profile ARN, show only their last part.
