# JYSV HERA 0.3.0 — 2026-10-29

**Worktrees** are here. An AI works in an isolated copy of your project on a branch of its own; when it is done, you look at what changed and merge it or throw it away. You can also give several AIs the same task and keep the best result.

### Added

- **Worktrees** (the Worktrees tab in the right-hand panel). [Guide](../../en/worktrees.md)
  - Type a name and create: HERA makes a branch `hera/<name>` and a folder `~/hera-worktrees/<project>/<name>`, and opens an AI or a terminal in it. The project folder does not change while it works.
  - Each card shows changed files, added and deleted lines, commits and files not yet committed.
  - **Changes**: every changed file in color, new files included. Write a note under it and it goes straight to the worktree's AI.
  - **Merge** with a merge commit, or squash into one commit. A conflict is undone completely, and HERA offers to hand it to the copy's AI.
  - **Discard / Delete** tells you first how many uncommitted files and unmerged commits would be lost. HERA only deletes worktrees and `hera/…` branches it made itself.
- **Give several AIs the same task and pick one.** 2 to 4 AIs work side by side, each in its own worktree. Compare the results and press **Keep this one**: only that result is merged, and HERA offers to delete the rest.
- **Helpers work in their own worktrees.** Switch it on in the multi-agent menu and new helpers open in worktrees of their own. The lead's briefing says where each helper works, on which branch, and how to check and bring in its result.
- **For first-time users**
  - A folder that is not a git repository is set up with one button, **Make it a git repository**. If there is no `.gitignore`, HERA writes a basic one first.
  - The project's `.env` files are copied into new worktrees. List more files to copy in `.worktreeinclude`.
  - A **Setup command for new worktrees** in the project's settings (for example `npm install`) runs in every new worktree.
- **`hera` CLI**: `hera spawn <agent> --worktree[=name]` opens a helper in its own worktree, and `hera worktrees` lists the project's worktrees.

### Changed

- Folders inside a worktree count toward its project on the Usage page, in `hera host` and for lanes.
- Tabs in a worktree show a branch icon, and in split view the pane shows the branch.
- The app's self-test runs the whole worktree flow (create, count changes, merge, undo a conflict, delete) on Windows, macOS and Linux for every release.
