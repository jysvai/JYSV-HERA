# JYSV HERA 0.3.4 — 2026-11-01

See what your AIs are doing right now, without reading every terminal.

### New

- **Live activity in the Folders tab.** While AIs work in a project, an **In progress** section above the folder tree shows:
  - each agent's progress, from its own to-do list or plan (or, with neither, how many of its subagents are done), the request you gave it and the step it is on;
  - the share of the work each model did (Opus, Sonnet, Haiku, gpt…) and an estimated cost at API list prices;
  - the subagents Claude Code starts, with their type, model and task;
  - the files being **read** (blue) or **changed** (orange), and by which agent. When two agents change the same file, it turns **red**. Click a file to open the tree at it; the tree marks the same files.

  A dot on the Folders tab tells you an agent is at work while another tab is open. It works with Claude Code (subagents and lanes included) and Codex, from the logs they already keep on your computer: nothing to install, nothing sent anywhere. See [Live activity](../../en/live-activity.md).

### Fixed

- A Codex tab that just started is matched to its conversation within seconds (it could take up to half a minute), so exact resume after a restart also knows it sooner.
