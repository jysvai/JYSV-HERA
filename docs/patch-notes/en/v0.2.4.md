# JYSV HERA 0.2.4 — 2026-10-28

Start multi-agent work straight from the backlog or an open session, and check for yourself that a download is genuine.

### Added

- **Multi-agent work without typing `hera`.** Hover a to-do and press ▶, or type a request in the add-to-do box and press the team button next to it. Choose an open agent session to lead (keeping its conversation, with the other agents open in the project as helpers), a team that starts fresh, or one agent alone. HERA opens the panes side by side, waits until every agent is ready, briefs the lead on its helpers and how to work with them, and hands over the task. The to-do shows which session is on it.
- **Add helpers to an open session.** The team button in the tab bar opens helpers next to the focused agent session. Its conversation stays as it is, and it learns how to work with them.
- **Automatic replies.** When an agent that got work with `hera send` finishes without replying, HERA sends its last screen to the sender after 20 quiet seconds, and tells the lead when a helper waits for an approval. You no longer relay results by hand.
- **Build provenance.** Every release file carries a Sigstore-signed build-provenance attestation. `gh attestation verify <file> --repo jysvai/JYSV-HERA` checks that this repository's GitHub Actions built it from the tagged source.
- **Locked runtime.** The packaged app ignores `NODE_OPTIONS` and `--inspect` and loads code only from its own integrity-checked `app.asar` (Electron fuses). Edited installed files make it refuse to start.
- **Code signing, ready to switch on.** Windows (SignPath Foundation) and macOS (Developer ID and notarization) signing are wired into the release workflow and take effect from the first release after the certificates are added. Until then Windows SmartScreen and the macOS first-run prompt appear as before.
- **Security checks.** CodeQL security queries and `npm audit` of the shipped dependencies run on every push. Report a vulnerability privately with the repository's *Security → Report a vulnerability*.

### Fixed

- **Right-panel tab labels wrapping onto two lines.** "Backlog · Folders · Usage · Lanes" stay on one line and scroll sideways instead of wrapping when they do not fit.
- **The desktop and Start menu icons keeping the old picture after an update.** The installer refreshes the Windows icon cache when it finishes.
