# JYSV HERA 0.3.9 — 2026-11-11

Go on with your Claude on your phone and back, and see what the AIs changed and what it affects.

### Added

- **Continue Claude on your phone and the web (Remote Control).** Turn on *Settings → Terminal → Continue Claude on your phone and the web*, and the Claude tabs HERA opens also show in the Claude app's **Code** tab and at claude.ai/code under the project's name. You can type on either side and the conversation goes on in the same session. Claude Code turns Remote Control on by itself only where Anthropic's rollout says so, which is why sessions could stop showing up on the phone; HERA now asks for it on the command line. The setting is read each time a tab starts, so ▶ and restored tabs follow it too. [Guide](../../en/remote-control.md)
- **Start sessions on this computer from your phone.** On a project's start screen, switch on **Start sessions here from your phone** under *Phone and web*. While HERA runs, it keeps a `claude remote-control` server in that folder, and your phone can start new sessions there. The panel shows when the server is connected, copies the claude.ai/code link, and shows the server's error with **Try again**. When you are signed in with claude.ai, the server starts even when `ANTHROPIC_API_KEY` is set in your environment (server mode refuses to start otherwise). HERA stops the servers with Ctrl+C when it quits, so the folder is free again right away.
- **Bring a phone or web session into a HERA tab.** **Bring a phone or web session** (on the start screen and in the **+** menu) opens `claude --teleport`, which lists this repository's sessions from your phone, from Remote Control and from the cloud. The one you pick goes on in a HERA tab.
- **What changed, and what it affects.** In *In progress*, a **Changed files** card shows how many files and lines the current work added and removed. Click it, or a changed file, to see each agent's changes line by line and the file's **Impact**: the files that import it, the files reached through those, and the related tests. A note box sends a comment to the agent that made the change, and **Ask to check** fills it in with the tests and files to check. The changes come from Claude Code's and Codex's own edits; the impact from TypeScript, JavaScript and Python imports. [Guide](../../en/live-activity.md#what-changed-and-what-it-affects)
- The [Lanes guide](../../en/lanes.md) has a new moving picture of a lane opening from the main Claude, in English and Korean.
